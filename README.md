# learn-golang

This repository is a hands-on Go learning project that follows topics covered in [Go Lang Myanmar Book](https://github.com/saturngod/go_lang_mm_book), a Burmese-language Go programming book. It contains small, runnable examples for practicing Go concepts, alongside a [`REFERENCE.md`](REFERENCE.md) with topic summaries and syntax.

## What the book covers

The linked book is organized as a 23-chapter learning path. It starts with Go's syntax, data types, development setup, and command-line tools, then covers control flow and core data structures such as arrays, slices, maps, and structs. It continues with functions, pointers, interfaces, packages and modules, and generics.

Later chapters introduce concurrency with goroutines and channels, error handling, useful standard-library packages, and testing. The book also builds a REST API, explores data structures and algorithms, and finishes with context, web development using Echo, and further learning resources.

## Running an example

From the project root, run an individual example with `go run` and its file path. For example:

```sh
go run ./0.hello_world/hello.go
```

See [`REFERENCE.md`](REFERENCE.md) for additional Go run commands and notes on the topics in this repository.
